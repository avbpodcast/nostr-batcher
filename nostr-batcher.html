nostr-batcher v1.04

Generate batches of nostr keypairs (npub / nsec, plus hex) and export them. Works offline; nothing leaves this page.

Terminal: python3 nostr_batcher.py opens a TUI, or python3 nostr_batcher.py -n 50 -f csv -o keys.csv.

The nsec values are the private keys. Whoever has one controls that identity for good. Save the file somewhere private. This page stores nothing: closing it loses keys you have not downloaded.

#npubnsecCopy

Public key = x-only coordinate of secret × G on secp256k1 (BIP-340, as used by NIP-01). npub/nsec = NIP-19 bech32 of the raw 32 bytes. Secrets come from crypto.getRandomValues with rejection sampling; the curve math is plain JavaScript BigInt, bundled inside this file. Compatible with the Python tool and any nostr client.
